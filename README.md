# Cc Skill Clickhouse Io

ClickHouse database patterns, query optimization, analytics, and data engineering best practices for high-performance analytical workloads.

## Overview

This repository preserves the AITMPL skill instructions and the available companion files in their original relative paths.

## Installation

```bash
git clone https://github.com/Brajesh31/claude-cc-skill-clickhouse-io-skill.git ~/.claude/skills/cc-skill-clickhouse-io
```

On Windows, use `%USERPROFILE%\.claude\skills\cc-skill-clickhouse-io` as the destination.

## Usage

Claude Code can load this skill when a request matches its description. Invoke directly with `/cc-skill-clickhouse-io` when needed.
